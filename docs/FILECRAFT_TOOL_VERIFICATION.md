# FileCraft tool verification ? 14 November 2026

48 browser utilities were processed with real fixtures and downloaded in Chromium desktop and Pixel 7 emulation. All 170 final core browser tests passed. This proves the tested workflows, not arbitrary-file fidelity or universal device support. No advertised tool was removed. ## Additional evidence

- tests/browser/security.spec.ts rejects forged inputs for all 48 tools and tests Word HTML active-link removal.
- PDF outputs parse with pdf-lib. DOCX contents are independently inspected through ZIP XML. XLSX outputs are reopened with ExcelJS and checked for FileCraft fixture values. Exported images are decoded back into browser bitmaps in additional targeted tests.
- Merge count, rotation angle, grayscale page dimensions and actual PDF compression size are checked. Office text outputs must contain expected fixture text.
- Core test suite: 170 passed across desktop/mobile Chromium, including 16 accessibility scans and screen-fit tests.
- Browser engines are loaded dynamically. Files are not posted to conversion APIs.

## BLOCKED / test boundaries

Firefox and WebKit: BLOCKED by missing Windows DLL dependencies, including on unrestricted retry. Pixel emulation is not a physical-device test. Large/hostile/encrypted documents, OCR, faithful Office page layout, arbitrary editable PDF content and every accessibility interaction are not certified by these samples. PDF page edits cap at 500 pages; PDF.js text extraction at 250; image PDF operations at 30; split at 100. Image/ZIP/page memory bounds also apply. Cancellation of running conversion computations is not implemented; selection validation can be cancelled.
