# FileCraft AdSense readiness
Status: BLOCKED for serving advertising pending real approval and certified consent setup. No ad units, fake ad blocks or paid-click prompts were created.

The optional script is gated by a valid configured publisher, public-site state, approval flag and CMP readiness flag. It is limited to content routes (/about, /blog, /faq, /features and guides). It is no longer unconditionally placed in the root head. No script is initially requested on authentication, dashboard or tool-processing routes. Configure Auto ads exclusions in Google before enabling because a loaded third-party script can persist across client navigation. The flags do not implement or certify a CMP.

ads.txt uses only the configured publisher ID. Cookie information is now a public page; legal/footer links are functional. Document handling copy describes actual browser processing and separately identifies database-backed account/contact metadata. Missing operator contact/legal details still require completion. GA4 remains unimplemented; no claim of analytics readiness beyond configuration placeholders.
