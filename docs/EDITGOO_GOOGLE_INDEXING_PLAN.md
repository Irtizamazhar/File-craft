## Owner workflow

1. Open URL Inspection and paste the exact WWW URL from the table. Record the current Google indexing status and Google-selected canonical if available.
2. Use Test Live URL when the indexed report is stale or a fix was deployed. Check indexing permission, fetch status, rendered preview and declared canonical. Resolve reported blockers and conflicting canonicals before submitting.
3. Review the existing homepage and Internet Speed Test submissions without duplicating them. For other priority pages, submit selectively when URL Inspection and the page checks support it. Record the actual submission date in the table.
4. Continue monitoring the Pages and Sitemaps reports. Sitemap discovery means Google knows the URL. Crawling means Google fetched it. Indexing means Google included it in its index. Ranking concerns its position for a search query.

Search Console requests are owner actions. This audit submitted none. A request does not guarantee indexing. [Google recrawl guidance](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl) · [URL Inspection](https://support.google.com/webmasters/answer/9012289)
